Create responsive image, photo and video galleries with justified, grid and masonry layouts, one-click Ready Patterns and a built-in lightbox.

== Description ==

Create beautiful image galleries with ShapedGallery's visual layout picker. Build justified, grid, masonry and video galleries without writing a line of code. It's made for photographers, designers, bloggers, agencies and anyone who wants a fast, responsive gallery on their WordPress website.

ShapedGallery makes building a photo gallery simple. Pick a layout, add images from your Media Library, style it in the live preview, and publish. What you see in the editor is what your visitors get, on desktop, tablet and mobile.

### The Fast, Block-First WordPress Gallery Plugin

Most gallery plugins make you work in a separate settings screen and guess how the result will look. ShapedGallery works inside the WordPress block editor you already use. Add the ShapedGallery block, choose a layout, and you're looking at your finished gallery right away.

Every gallery is rendered on the server as clean HTML. Your images load with the rest of the page instead of jumping into place a moment later, and search engines can read your images, titles and captions like any other content. Pages without a gallery load none of the plugin's files at all, so your site stays fast.

### Responsive Gallery Layouts

**Justified Gallery**
Rows of equal height with image widths balanced so every row fills the space edge to edge. The best choice for photographs of mixed sizes and orientations, and nothing gets cropped.

**Grid Gallery**
Equal tiles in a set number of columns. A clean, tidy look for portfolios, products, team photos and logos.

**Masonry Gallery**
Pinterest-style columns of different heights with the gaps closed, so tall and wide images sit together naturally.

Every layout is fully responsive. Set columns and spacing separately for desktop, tablet and mobile so your gallery looks right on every screen.

### Ready Patterns: Start With a Designed Gallery

Not sure where to begin? Open the Ready Patterns library, preview a design, and insert it with one click. Patterns are grouped by layout, and each one stays fully editable, so you just swap in your own photos. You can open the library from the block toolbar, the editor header or the dashboard.

### Video Gallery Support

Mix photos and videos in the same gallery, or build a video gallery on its own. Add:

* Videos from your Media Library
* External videos by URL
* YouTube videos

Videos open in the same lightbox as your images, so visitors get one smooth viewing experience.

### Built-in Lightbox Gallery

Let visitors view your photos full size without leaving the page. The lightbox is built on the browser's own `<dialog>` element, so it's fast and accessible:

* Zoom and pan on desktop, pinch and swipe on phones and tablets
* Image counter
* Keyboard navigation with arrow keys, and Escape to close
* Plays Media Library videos, external videos and YouTube
* Loads only on pages where a gallery opens it

== Installation ==

= Minimum Requirements =

* WordPress 6.8 or later
* PHP 8.1 or later

On an older PHP version the plugin shows a notice instead of causing a fatal error.

= Automatic Installation (Easiest Way) =

1. In your dashboard, go to **Plugins → Add New**.
2. Search for **ShapedGallery**.
3. Click **Install Now**, then **Activate**.

= Manual Installation =

1. Download the plugin zip.
2. Go to **Plugins → Add New → Upload Plugin**, choose the zip and click **Install Now** — or upload the unzipped `easy-lightbox-wp` folder to `/wp-content/plugins/`.
3. Activate the plugin through the **Plugins** screen.

= Getting Started =

1. Go to **ShapedGallery → Dashboard** and click **Create New Gallery** — or click **Use Ready Patterns** to start from a design.
2. Alternatively, add the **ShapedGallery** block to any post or page.
3. Pick a layout, add your images and videos, and publish.
4. To show a saved gallery elsewhere, copy its shortcode — `[shaped_gallery id="123"]` — from **Saved Galleries**.

== Frequently Asked Questions ==

= What is ShapedGallery? =

A photo and video gallery builder for WordPress. It creates responsive justified, grid and masonry galleries from your Media Library, with a visual layout picker, Ready Patterns and a built-in lightbox.

= Do I have to use the block editor? =

To build a gallery, yes — the editor is WordPress's own, on a hidden gallery post type. To place one, no: every saved gallery has a permanent shortcode you can use in any editor, page builder, widget or template.

= Will editing a gallery update it everywhere? =

Yes. A page embeds a reference to the gallery, never a copy, so there is no re-sync step.

= Can I add videos? =

Yes: videos from your Media Library, external videos by URL, and YouTube videos. They play in the same lightbox as your images.

= Is it mobile-friendly? =

Yes. Every layout is responsive, with separate desktop, tablet and mobile values for columns and spacing, and the lightbox supports pinch-to-zoom and swipe.

= Can I password-protect a gallery? =

Yes. Each gallery can be public, password-protected or private.

= Does the lightbox load on every page? =

No. The viewer is a separate bundle, requested only by a page with a gallery whose click action actually opens it. (The one exception is a site upgraded from Easy Lightbox, where the compatibility mode keeps the old site-wide lightbox working.)

= Which page builders are supported? =

Elementor, Divi, WPBakery, Oxygen, Beaver Builder and Bricks each have a dedicated element. Elementor is on by default; enable the others in **ShapedGallery → Settings → Integrations**. Anywhere else, use the gallery's shortcode.

= I used Easy Lightbox. Will my site break? =

No. Existing `litebox` links, image sets and the automatic lightbox on WordPress's `[gallery]` shortcode keep working through a compatibility mode that is switched on automatically for upgraded sites. Nothing on your site changes until you choose to build a gallery.
